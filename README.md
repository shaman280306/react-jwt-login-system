# 🔐 React JWT Login System

A professional React-based authentication demonstration implementing simulated JWT generation, token storage, role display, and protected UI.

## 🚀 Features

- Username and password authentication
- Login validation
- Simulated JWT/token generation
- User ID and role stored in token payload
- Token storage using localStorage
- Protected Dashboard
- Authentication state persistence
- Logout functionality
- Responsive professional UI

## 🛠️ Technologies

- React
- Vite
- JavaScript
- CSS
- Browser localStorage
